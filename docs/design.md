# HexPick 设计方案 v2

日期：2026-10-11　平台：仅 macOS（Apple Silicon，macOS 13+）

## 1. 定位

常驻菜单栏的桌面工具。任意应用里按快捷键（默认 ⌘H，可改），当前屏幕弹出海克斯大乱斗风格的强化符文选择界面，从插件预设的内容里抽卡。
场景：开会/课堂点人、今天吃什么、任何“从一堆东西里选一个”的趣味时刻。

## 2. 抽卡规则（对齐 ARAM: Mayhem 海克斯大乱斗）

| 游戏规则 | HexPick 对应 |
|---|---|
| 一局 4 次选择（3/7/11/15 级） | 一“局”默认 4 次选择，插件可改 `screens` |
| 每次给 3 个强化，玩家选 1 个 | `drawCount` 默认 3 |
| 每次选择品质随机，三张同品质 | 每次先掷品质，三张同档 |
| 每张卡可刷新 1 次，刷新出同品质 | `rerollsPerCard` 默认 1，同品质替换 |
| 出现过的强化本局不再出现 | 本局内已展示过的条目不再出现 |
| 第 1、2 次不能都是白银 | 同样保留 |
| 金色刷新：白银/黄金轮有概率让某张卡刷新时升一档 | `goldenRerollChance`，默认 0.15 |
| 品质概率官方未公布 | 默认 白银 50 / 黄金 45 / 棱彩 5（社区实测值），插件可改 |
| 一局结束显示已获得的强化 | 局末“构筑总结”，展示本局选中的 4 张 |
| 羁绊套装（2026-06 版本已移除） | 不做 |

扩展规则（游戏里没有，生活场景需要）：
- 条目可固定品质：最爱吃的固定为棱彩，只在棱彩轮出现。
- 只在有可出条目的品质里掷骰，避免空轮。
- `removeAfterPick`：跨局移除已选中条目，适合轮流点名。
- `pickTimer`：可选倒计时，到时自动随机选一张（默认关闭）。

## 3. 卡片样式（对齐游戏）

游戏卡片元素：品质边框 + 方形图标 + 名称 + 效果描述 + 品质标识。
- 白银：冷银金属边框，灰蓝底。
- 黄金：暖金边框，微光扫过。
- 棱彩：流动彩虹边框 + 闪光粒子。
- 描述里的关键词高亮（游戏中数值、关键词有颜色），用标签语法实现。
- 依次翻牌入场，揭晓音按品质区分，选中后放大光爆，其余卡淡出。
- 按用户要求改用游戏原版素材（2026-10-11 决定）：卡底、三档边框、光泽、未选中遮罩、棱彩全息、金色刷新扫光、图标底座、
  选择界面特效（出现闪光、悬停扫光、选中光环与星芒、未选中溶解、刷新擦出、棱彩电弧）、阶段图标、嚎哭深渊地图背景、
  112 个大乱斗强化图标（插件用 `lol:名称` 引用）。素材由 `tools/fetch-game-assets.mjs` 从 CommunityDragon 下载，版权归 Riot Games。
- 音效仍为 Web Audio 合成：游戏音效在 Wwise 音频包里，CommunityDragon 不提供解码后的文件。插件可自带音效覆盖。
- 选中后与游戏一致：其余卡溶解消失，多次选择的插件在动画后自动进入下一次。

## 4. 插件：四层可扩展

插件是 `~/Library/Application Support/HexPick/plugins/` 下的一个文件夹：

```
food/
  plugin.json     必需：规则 + 内容
  card.html       可选：自定义卡片模板
  style.css       可选：自定义样式
  assets/         可选：图片
  sounds/         可选：音效
```

### 4.1 内容层
条目字段：`title`、`description`（富文本标签）、`icon`（emoji 或插件内图片路径）、`image`（大图）、`rarity`、`weight`、`tags`，以及任意自定义字段 `data`。
最简写法仍可只写字符串数组。

描述标签（模仿游戏描述的配色）：
```
<gold>1750 金币</gold> <keyword>护盾</keyword> <ap>+60% AP</ap> <ad>+100% AD</ad>
<b>粗体</b> <i>斜体</i> <br> <color value="#ff5577">任意颜色</color>
```

### 4.2 排版层
- 内置布局：`augment`（默认，游戏原样）、`portrait`（大头像，适合点人）、`text`（大字，适合投屏）。
- 自定义模板 `card.html`：`{{title}}` 转义输出，`{{{description}}}` 富文本输出，`{{data.xxx}}` 读自定义字段，`{{#field}}…{{/field}}` 有值才显示，`{{rarityLabel}}` 等内置变量。
- 每张卡渲染在独立 Shadow DOM 中，插件 CSS 只作用于自己的卡片，不会弄坏主界面。

### 4.3 主题层
`theme` 字段覆盖设计变量：三档品质颜色、背景、字体、品质名称（如把“白银/黄金/棱彩”改成“普通/心动/本命”）、每档揭晓音效文件。

### 4.4 规则层
`screens`、`drawCount`、`rerollsPerCard`、`rarityWeights`、`goldenRerollChance`、`removeAfterPick`、`pickTimer`、`noRepeat`（`session` 本局不重复 / `none`）。

### 4.5 安全边界
插件只有数据、HTML 模板和 CSS，不能执行脚本：
- 模板经过净化，移除 script、iframe、事件属性和 javascript: 链接。
- 内容安全策略禁止内联脚本和任何网络请求。
- 图片、音效只能读插件自己目录里的文件（自定义协议 + 路径越界检查）。
- 校验失败的插件不加载，在设置页显示文件名和出错字段。

## 5. 应用结构

- 菜单栏图标：呼出、切换插件、设置、打开插件目录、退出。无 Dock 图标。
- 浮层窗口：无边框、透明、最高层级置顶，出现在鼠标所在屏幕，全屏应用和所有桌面空间里都能显示。
- 设置窗口：快捷键录制（按下组合键即保存，冲突时提示）、插件列表（启用/停用/重新加载/错误）、音量、开机启动。
- 插件目录热加载，保存即生效。
- 键盘：1/2/3 选择，R 刷新悬停卡片，Space 下一次，Tab 切插件，M 静音，Esc 关闭。

技术栈：Electron 44 + React 19 + TypeScript + electron-vite + Vitest，与 lolPing 一致；不需要原生钩子和辅助功能权限。

## 6. 风险

- ⌘H 是系统“隐藏应用”快捷键，设为全局后所有应用的 ⌘H 都会被接管。按用户要求保留为默认，可在设置里改。
- 安装包仅 ad-hoc 签名，首次打开需在“隐私与安全性”中允许。
- 打包了 Riot Games 的素材，公开分发前需评估版权风险，必要时按要求移除。
- 品质概率无官方数据，默认值来自社区实测，可在插件里调整。

## 7. 实施阶段

1. 规则引擎：插件校验 + 抽卡状态机（局、选择、刷新、金色刷新、不重复），单元测试覆盖。
2. 主进程：快捷键、菜单栏、浮层窗口、插件目录加载与热更新、插件资源协议。
3. 浮层 UI：游戏风格卡片、三种内置布局、描述标签、模板引擎 + Shadow DOM、动画音效。
4. 设置窗口：快捷键录制、插件管理。
5. 示例插件：今天吃什么（augment 布局）、点名（portrait）、自定义模板示例。
6. 打包 dmg，浏览器演示模式截图验证。
